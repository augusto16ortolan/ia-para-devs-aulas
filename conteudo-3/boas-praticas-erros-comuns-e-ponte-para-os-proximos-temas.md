# Boas práticas, erros comuns e ponte para os próximos temas

Depois de entender estrutura, contexto e comportamento, vale olhar para os erros mais comuns que enfraquecem prompts para agentes.

## Erros comuns

Entre os problemas mais frequentes, vale destacar:

* prompts vagos demais;
* objetivos misturados na mesma instrução;
* ausência de formato de saída;
* instruções contraditórias;
* excesso de autonomia sem limite claro;
* uso de ferramentas sem critério.

## Boas práticas

Para melhorar a qualidade do prompt, normalmente ajuda:

* definir um objetivo por vez;
* dizer o papel do agente;
* orientar formato de resposta;
* dizer quando usar ferramentas;
* revisar e iterar o prompt;
* testar pequenas variações quando o resultado não vier bom.

## Iterar também faz parte

Nem sempre o primeiro prompt será o melhor.

Muitas vezes, a melhoria vem de pequenos ajustes:

* trocar termos vagos por instruções específicas;
* acrescentar contexto relevante;
* remover excesso de informação;
* definir melhor o tipo de saída.

## Ponte para os próximos temas

Esse conteúdo abre caminho para os próximos tópicos da disciplina, porque vários deles dependem diretamente de boas instruções:

* copilotos de código;
* MCP;
* servidores MCP;
* agentes com ferramentas;
* integrações externas.

Ou seja, prompt engineering é uma base prática para quase tudo o que vem depois.
