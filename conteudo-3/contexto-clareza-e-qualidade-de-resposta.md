# Contexto, clareza e qualidade de resposta

Mesmo com um modelo bom, uma resposta pode sair ruim quando o prompt é vago, curto demais ou mal estruturado.

Por isso, engenharia de prompts também é um trabalho de clareza.

## Quando falta contexto

Sem contexto suficiente, o agente tende a:

* assumir coisas que você não disse;
* responder de forma genérica;
* não entender o público-alvo;
* errar o nível de profundidade;
* escolher um formato inadequado.

## Quando sobra contexto desnecessário

Mais contexto nem sempre significa melhor resultado.

Se o prompt traz muita informação irrelevante, o agente pode:

* perder foco;
* dar peso para detalhes pouco importantes;
* misturar objetivos;
* entregar respostas mais confusas.

## Clareza vence excesso

Na maioria dos casos, o melhor caminho é combinar:

* contexto suficiente;
* objetivo claro;
* linguagem direta;
* formato definido;
* poucas ambiguidades.

## Exemplo rápido

Prompt ruim:

* "Fale sobre agentes."

Prompt melhor:

* "Explique o que é um agente de IA para alunos de graduação em Computação, usando linguagem simples e um exemplo de uso no desenvolvimento de software."

O segundo prompt melhora público, tom, objetivo e escopo.
