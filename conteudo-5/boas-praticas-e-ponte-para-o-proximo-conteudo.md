# Boas práticas e ponte para o próximo conteúdo

Entender o conceito de MCP é importante, mas também vale pensar em boas práticas desde o início.

## Escopo das ferramentas

Uma boa regra é evitar expor ferramentas com escopo maior do que o necessário.

Ferramentas muito amplas podem:

* dificultar controle;
* aumentar risco;
* tornar o comportamento do cliente menos previsível.

## Validação e segurança

Sempre que um sistema de IA acessa capacidades externas, vale pensar em:

* validação de entrada;
* validação de saída;
* permissões;
* observabilidade;
* rastreabilidade.

Isso não é detalhe secundário. Faz parte da arquitetura.

## Organizar antes de expandir

Antes de sair conectando tudo, vale perguntar:

* esta ferramenta precisa mesmo ser exposta?
* o cliente realmente precisa desse recurso?
* a interface está clara?
* os riscos estão controlados?

## Ponte para o próximo conteúdo

O próximo passo natural é sair da visão conceitual e montar algo concreto.

No conteúdo seguinte, vamos transformar essa ideia em prática e construir um servidor MCP simples, entendendo como expor capacidades reais para um cliente.
