# Como o MCP funciona na prática

Na prática, o valor do MCP aparece quando ele deixa de ser só um conceito e passa a organizar integrações reais.

## Expondo uma API como ferramenta

Um caso comum é expor uma API externa como uma ferramenta que o cliente pode usar.

Por exemplo:

* consultar estoque;
* buscar dados de clientes;
* recuperar pedidos recentes;
* obter informações de um sistema interno.

## Expondo dados como recurso

Além de ações, também faz sentido expor dados e contextos como resources.

Isso pode incluir:

* arquivos;
* documentos;
* tabelas;
* conteúdos internos;
* informações de apoio para resposta.

## O que muda em relação ao uso de prompt puro

Quando usamos só um prompt, o modelo responde com base no texto disponível.

Quando usamos MCP, o sistema pode acessar capacidades externas organizadas, ampliando o que ele consegue fazer com informação real e atualizada.

## Exemplo rápido

Um agente sem MCP pode apenas responder com o que já recebeu em texto.

Um agente com MCP pode:

* consultar uma API;
* ler um recurso específico;
* buscar um arquivo;
* usar uma ferramenta e depois responder com base nisso.
