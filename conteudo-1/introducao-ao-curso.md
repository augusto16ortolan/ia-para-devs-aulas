# Introdução ao curso

Este material apresenta uma visão prática de como a IA entrou no dia a dia do desenvolvimento de software.

Em vez de focar em teoria pesada, o curso trabalha com uma ideia simples: entender o suficiente para usar bem.

Ao longo dos próximos tópicos, o aluno vai ver:

* como LLMs funcionam na prática;
* como escrever prompts melhores;
* como usar copilotos de código;
* o que é MCP e por que ele é importante;
* como agentes se organizam e usam ferramentas externas.

## O que o aluno deve levar desta disciplina

* Uma visão clara do ecossistema de IA aplicada ao desenvolvimento.
* Capacidade de reconhecer quando uma ferramenta de IA ajuda de verdade.
* Noções básicas de integração entre agentes, ferramentas e dados.
* Um repertório mínimo para conversar sobre IA com mais segurança técnica.

## Como o curso vai seguir

1. entender a base dos LLMs;
2. aprender a formular prompts melhores;
3. usar copilotos de código com critério;
4. conhecer o MCP;
5. construir um servidor MCP simples;
6. entender agentes e orquestração;
7. conectar agentes a ferramentas reais.
