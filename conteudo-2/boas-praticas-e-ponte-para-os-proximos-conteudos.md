# Boas práticas e ponte para os próximos conteúdos

Depois de entender como o modelo funciona e onde ele ajuda, o próximo passo é aprender a usá-lo com mais qualidade.

## Boas práticas no uso de LLMs

Algumas práticas fazem bastante diferença:

* dar contexto suficiente;
* pedir uma coisa por vez quando a tarefa for complexa;
* especificar o formato de saída;
* revisar respostas importantes;
* testar mais de uma formulação quando o resultado vier ruim.

## O modelo sozinho nem sempre basta

Em muitos casos, apenas um prompt não resolve o problema inteiro.

À medida que as tarefas ficam mais complexas, surge a necessidade de:

* consultar dados externos;
* chamar ferramentas;
* acessar arquivos;
* usar memória;
* estruturar melhor o comportamento do sistema.

## Ponte para os próximos conteúdos

É aqui que entram os próximos temas da disciplina:

* engenharia de prompts;
* copilotos de código;
* MCP;
* servidores MCP;
* agentes;
* integrações com ferramentas externas.

Em outras palavras, este conteúdo explica a base. Os próximos mostram como transformar essa base em uso real dentro de fluxos de desenvolvimento.
