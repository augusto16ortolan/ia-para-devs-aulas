# Testando, usando e conectando com o próximo conteúdo

Depois de montar um servidor MCP simples, o próximo passo é validar se ele realmente funciona como esperado.

## O que vale testar

Mesmo num cenário introdutório, vale observar:

* se o servidor inicializa corretamente;
* se a capability aparece como esperado;
* se a entrada é aceita no formato certo;
* se a resposta volta de forma clara;
* se erros simples são tratados.

## O comportamento do cliente importa

Também é útil perceber como o cliente consome essa capacidade.

Isso ajuda o aluno a entender:

* se a descrição da tool está clara;
* se os parâmetros fazem sentido;
* se a saída ajuda de fato o uso posterior pelo agente ou assistente.

## Ligação com sistemas maiores

Mesmo um servidor simples já pode fazer parte de algo maior.

Ele pode ser usado por:

* um assistente técnico;
* um copiloto de código;
* um agente com acesso a ferramentas;
* um sistema com múltiplos serviços organizados.

## Ponte para o próximo conteúdo

Esse ponto conversa diretamente com o próximo tema da disciplina.

Quando um agente passa a usar tools e resources expostos por servidores organizados, a conversa naturalmente evolui para arquitetura de agentes e orquestração.
