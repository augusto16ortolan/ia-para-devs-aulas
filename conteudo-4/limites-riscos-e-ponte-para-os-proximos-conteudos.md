# Limites, riscos e ponte para os próximos conteúdos

Copilotos são muito úteis, mas não são mágicos. Entender seus limites evita dependência cega e ajuda o aluno a usar essas ferramentas com mais maturidade.

## Riscos comuns

Entre os principais riscos, vale destacar:

* código errado com aparência convincente;
* sugestões inseguras;
* uso de APIs desatualizadas;
* perda de contexto em mudanças maiores;
* aceitação automática sem entendimento real;
* sensação falsa de produtividade.

## O risco da confiança exagerada

Quanto melhor a ferramenta escreve, maior pode ser a tentação de confiar sem revisar.

Esse é um dos pontos mais delicados do uso de IA no desenvolvimento: respostas e sugestões podem parecer excelentes na forma, mas falhar no conteúdo.

## Produtividade com supervisão humana

O cenário mais saudável não é “IA faz tudo”, mas sim:

* IA acelera;
* desenvolvedor valida;
* testes confirmam;
* entendimento humano continua central.

## Ponte para os próximos conteúdos

Este tema se conecta diretamente com os próximos tópicos da disciplina.

Quando os copilotos ficam mais capazes, eles começam a:

* chamar ferramentas;
* acessar contexto estruturado;
* consultar recursos externos;
* se comportar mais como agentes.

É justamente aí que entram MCP, servidores MCP e integração de agentes com ferramentas externas.
