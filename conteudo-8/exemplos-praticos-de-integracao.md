# Exemplos práticos de integração

A melhor forma de entender integração é olhar para exemplos concretos.

## APIs

Um agente pode usar APIs para:

* consultar pedidos;
* recuperar dados de clientes;
* verificar estoque;
* buscar métricas de um sistema;
* consultar documentação viva.

## Bancos de dados

Também pode fazer sentido conectar um agente a um banco quando ele precisa:

* buscar registros;
* verificar histórico;
* cruzar informações;
* responder perguntas sobre dados internos.

## Arquivos e documentos

Outra integração comum é com:

* arquivos locais;
* PDFs;
* documentação do projeto;
* logs;
* artefatos internos de apoio.

## Rotinas e automações

Em alguns casos, o agente não apenas consulta, mas também aciona algo, como:

* iniciar uma rotina;
* chamar um processo interno;
* disparar uma automação controlada;
* consolidar uma etapa de trabalho.

## Exemplo rápido

Um agente de suporte técnico pode:

* consultar uma API de incidentes;
* ler logs recentes;
* resumir o problema;
* sugerir um próximo passo com base no estado atual.
