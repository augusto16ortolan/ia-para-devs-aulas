# Machine Learning e Inteligência Artificial para Devs

[AQUI VAI UMA IMAGEM]

Prompt da imagem:
Criar uma imagem de capa para um GitBook sobre IA aplicada ao desenvolvimento
de software. A cena deve transmitir tecnologia, aprendizado e praticidade, com
um desenvolvedor em destaque, elementos sutis de código, blocos representando
LLMs, um copiloto de código e uma conexão simbólica com agentes e ferramentas.
O visual precisa ser editorial, elegante e moderno, com fundo claro, cores
equilibradas entre azul, verde e cinza, composição limpa e profissional, sem
parecer infantil ou futurista demais. Proporção 16:9, alta nitidez e foco em
uso como capa de material didático.

Este GitBook foi pensado para apresentar, de forma leve e prática, os
principais conceitos de IA generativa aplicados ao desenvolvimento de
software.

A ideia não é aprofundar matemática, treino de modelos ou teoria pesada.
O foco é dar ao aluno o contexto necessário para:

* entender como LLMs funcionam na prática;
* escrever prompts melhores para assistentes e agentes;
* usar copilotos de código com mais critério;
* conhecer o Model Context Protocol;
* montar um servidor MCP simples;
* enxergar como agentes tomam decisões e se conectam a ferramentas externas.

## Como este material esta organizado

Cada conteúdo segue uma linha parecida:

1. visão geral do tema;
2. explicação objetiva dos conceitos principais;
3. exemplos práticos;
4. imagem ilustrativa com prompt para geração posterior;
5. atividades para fixação.

## Observação pedagógica

Este material foi planejado para ser mais panorâmico do que técnico em
profundidade. O objetivo é que o aluno termine o semestre sabendo:

* o que cada tecnologia faz;
* quando ela faz sentido;
* quais são os riscos;
* como conectar os conceitos no desenvolvimento real.
